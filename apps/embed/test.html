Loco Widget Embed Test

If everything is working correctly, you should see a blue chat button in the bottom-right corner of the page.

Test Actions:

  • Click the button to open the widget
  • Click again to close it
  • Hover over the button to see the scale animation

JavaScript API:

Open the browser console and try:

  • LocoWidget.show() - Open the widget
  • LocoWidget.hide() - Close the widget
  • LocoWidget.destroy() - Remove the widget
